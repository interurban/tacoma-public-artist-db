# Tacoma Public Artist DB

A public list of artists and art spaces in Tacoma, kept so more people can find local artists and their work. [Tacoma IRL's artist directory](https://tacomairl.com/art/db/) uses it.

**This is a work in progress.** It started with a handful of artists and is growing slowly. Some details may be missing or out of date, and we may have got something wrong.

## If you're listed

Email [hello@tacomairl.com](mailto:hello@tacomairl.com) with what should change: your name as you want it written, what you make, the part of Tacoma you work in, whether visitors can come to your studio, and your website or social links.

If we've got anything wrong, tell us and we'll fix it. You don't need to explain why, and you don't need a GitHub account.

## If you're not listed

Email us the same details and we'll look into adding you. Being listed is free. There are no rankings, ads or paid placements.

## What we list

For each artist: your name, what you make, the part of Tacoma you're in if you've said so, whether people can visit your studio, links to your own website and accounts, and a short description.

We only add what a public source says, usually your own website, and we link to it. We never add home addresses, phone numbers, private emails or exact studio locations. If something isn't public, we leave it blank.

## Reusing the list

The data is free to reuse under [CC0](LICENSE-DATA); no credit is required, though a link back is nice. The code and documentation use [MIT](LICENSE). Those licences cover this list, not other people's websites, artwork or photographs.

## Ask your agent

If you use a coding agent, you can paste this and fill in the brackets:

> Update my entry in https://github.com/interurban/tacoma-public-artist-db. Read AGENTS.md and CONTRIBUTING.md first. My name is [name]. Use [official website URLs] and these changes: [changes]. Find my existing file before creating one, cite a public source for each fact, and leave anything unconfirmed blank. Do not add my home address, phone number or private email. Run the repository checks and open a pull request. Do not merge or publish it.

For a new entry, replace "Update my entry" with "Propose a new draft entry for me." Prefer GitHub? See [CONTRIBUTING.md](CONTRIBUTING.md).
