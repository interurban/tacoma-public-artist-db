# Tacoma Public Artist DB

An open, community-maintained directory of Tacoma artists and art spaces, started by [Tacoma IRL](https://tacomairl.com/art/).

The initial repository design, contribution guide, agent instructions, schema, validator and two sourced artist drafts are being prepared in a pull request. All listing changes will be proposed through pull requests for maintainer review.

Data in `artists/` uses [CC0 1.0 Universal](LICENSE-DATA). Code, schemas and documentation use [MIT](LICENSE). These licenses do not cover the external sites linked as evidence or any artwork and photographs.

See the [original proposal](https://github.com/interurban/tacoma-irl-astro/issues/152) for background. This repository does not deploy the Tacoma IRL website.
